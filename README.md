# cosmicdrift

Колекція браузерних ігор — кожна гра є одним самодостатнім HTML-файлом без залежностей.

## Ігри

### 🚀 Cosmic Drift
Аркадний космічний шутер: 5 секторів, боси, зброя, сюжет.
Файл: `cosmic_drift_v5 (2).html`

### 🏡 Farm Haven: Новий Початок
Фермерський симулятор про відродження дідусевої ферми та магічного Дерева Життя.
Файл: `farm-haven.html`

- Розчищай занедбану ферму від бур'янів, каміння та дерев
- Вирощуй 11 культур, доглядай 9 видів тварин
- Переробляй ресурси у 6 виробничих будівлях (млин, сироварня, джемоварня…)
- Виконуй завдання 5 мешканців долини (тесляр, пекарка, рибалка, бджоляр, старійшина)
- Досліджуй 10 територій: ліс, озеро, шахту, гори, водоспад, руїни храму…
- Пори року, сезонні культури та фестивалі (ярмарок, свято врожаю, зимовий карнавал)
- Відроди Дерево Життя (5 рівнів) та відкрий Новий континент
- Автозбереження прогресу в браузері, підтримка мобільних пристроїв
