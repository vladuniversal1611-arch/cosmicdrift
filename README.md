# cosmicdrift

Колекція мобільних HTML5-ігор.

## 🌋 Lava Survivor — `index.html`

Endless-survival roguelite: острів тоне в лаві — стрибай угору, збирай скарби,
відкривай героїв і повертайся по «ще одну спробу».

- **7 локацій**: Вулкан, Печери, Стародавній храм, Джунглі, Засніжені вершини, Небесний острів, Магічний світ
- **Пастки**: лава, вогняні кулі, каміння, шипи, вибухові бочки, крихкі та рухомі платформи
- **Roguelite**: після кожного етапу — вибір 1 із 3 випадкових покращень
- **32 герої** з унікальними бонусами
- **Домашня база**: Табір, Кузня, Магічний портал, Сховище, Статуя героїв
- **Щоденні місії**, **152 досягнення**, **5 щотижневих івентів**
- **Косметика** (скіни, сліди, крила, аури, улюбленці) — без впливу на баланс
- **Офлайн-нагороди** (до 8 годин), щоденні бонуси за вхід
- Монетизація: реклама за винагороду + преміум-перепустка (стаби, див. `ANDROID.md`)

**Керування**: тримай ліворуч/праворуч — рух (стрибки автоматичні), швидкий тап —
стрибок у повітрі (коли відкрито здібність). На ПК — стрілки/WASD + пробіл.

Запуск: просто відкрий `index.html` у браузері.
Збірка для Android / Google Play: див. [`ANDROID.md`](ANDROID.md).
