# ⚗️ Mystic Alchemy Lab

A **bright, relaxing alchemy fusion puzzle** for ages 6–70. You are the keeper
of an ancient magical laboratory hidden beneath floating islands. Its crystals
have gone dark — restore their power by solving handcrafted alchemy puzzles, and
watch abandoned ruins bloom back into a magnificent magical academy.

Built with **pure HTML + CSS + JavaScript** (Canvas rendering, WebAudio sound).
**No external libraries. Offline. No ads. No tracking.** Ready for Android
export with Capacitor or Cordova.

> Visual identity is deliberately **bright & warm — a light "summer / winter"
> palette** (soft skies, glossy pastel glass, sparkles). It is *not* a dark
> sci-fi style.

---

## 🎮 The core mechanic — *Essence Fusion* (not Water Sort)

This is **not** a water-sort clone. Energy **evolves upward** — it never just
stacks by color.

1. **Tap a flask** to lift its top **essence**.
2. **Tap another flask** — if its top essence is the **same tier/color**, the
   two **fuse into ONE essence of the next tier** (think *2048 × alchemy*).
3. Keep fusing up the chain. Fuse the two highest-tier essences and you **forge
   an Ancient Core** ✦ — the goal of every level.
4. Reach the target number of cores before you run out of **moves**.

Because fusion consumes two and produces one, every level is a compact strategy
puzzle about **sequencing and space**, not sorting.

### Twists introduced across the campaign (a new one every ~10–15 levels)

| Icon | Mechanic | Effect |
|------|----------|--------|
| 🔒 | **Locked essence** | Frozen in place until freed (🧲 Magnet booster) |
| ❄ | **Frozen essence** | Tap to thaw (costs a move) before it can fuse |
| ◎ | **Portal flask** | Linked in pairs — a drop emerges from its twin |
| ⊟ | **Splitter flask** | Fusing here spawns an extra lower essence |
| ↻ | **Shift flask** | Colors drift under its magic |
| 🟢 | **Living slime** | Nibbles an essence down a tier — fuse fast! |
| 👑 | **Boss levels** | Every 10th level; the boss changes the rules mid-play |

## 🗺️ Content

- **8 worlds × 40 levels = 320 handcrafted-feeling, always-solvable levels.**
  Levels are generated by a **reverse-fusion generator** seeded per level, so
  every puzzle is deterministic and guaranteed to have a solution path — with a
  smooth difficulty curve: *Easy → Medium → Hard → Expert → Master → Legend.*
- **Worlds:** Ancient Forest · Crystal Cave · Sky Islands · Frozen Temple ·
  Volcano Forge · Moon Laboratory · Dragon Observatory · Void Dimension.
  Each has its own bright background, palette, ambient music, and mechanics.
- **Boss puzzles** every 10 levels: Ancient Dragon, Crystal Golem, Shadow
  Alchemist, Dark Wizard — each bends the rules while you play.

## 💠 Meta-progression & economy

- Currencies: **🪙 Coins · 💎 Crystals · ✨ Magic Dust · 🗝️ Golden Keys** + **❤️ Lives** (regen over time).
- **The Laboratory** — spend resources to rebuild rooms (Herb Garden, Mana
  Fountain, Arcane Library, Grand Spire…), visibly restoring the lab.
- **Alchemist level & XP**, avatars, flask skins, shop.

## ▶️ Run it locally

Just open `index.html` in any modern browser, or serve it:

```bash
npm start          # runs `npx serve .`
# or
python3 -m http.server 8000
```

Then visit the page on a phone-sized viewport (it's designed portrait-first).

## 📱 Export to Android (Capacitor)

The project is already Capacitor-compatible (`webDir` is the project root).

```bash
# 1. install deps
npm install

# 2. add the Android platform
npx cap add android

# 3. copy web assets into the native project
npx cap sync

# 4. (optional) generate launcher icons/splash from assets/icon.svg
#    provide a 1024x1024 source and run:
npx capacitor-assets generate --iconBackgroundColor '#e9f7ff'

# 5. open in Android Studio and Run, or build a debug APK:
npx cap open android
#    or headless:
cd android && ./gradlew assembleDebug
```

The APK will be at `android/app/build/outputs/apk/debug/app-debug.apk`.

### Cordova (alternative)

The same static files work under Cordova — copy `index.html`, `style.css`,
`game.js`, and `assets/` into your Cordova project's `www/` directory.
