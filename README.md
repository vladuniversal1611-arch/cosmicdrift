# 👑 Block Kingdom — Crystal Forge

Преміальна казуальна HTML5-головоломка з розміщенням фігур. Vanilla JS + Canvas 2D,
без жодних бібліотек. Готова до пакування для Google Play (WebView / TWA / Capacitor).

## Гра

Будуй магічне поле з фігур. Заповнена лінія (рядок або стовпець) вибухає з
частинками, світінням і тряскою екрана. Поле поступово «оживає»: з рівнями
відкриваються нові механіки.

### Механіки (відкриваються поступово)
| Рівень | Механіка | Опис |
|---|---|---|
| 6  | 🪙 Золоті блоки | додаткові монети |
| 10 | 💎 Кристали | звільни, очистивши лінію |
| 16 | ❄️ Лід | очищати двічі |
| 24 | ⛓️ Ланцюги | перший клір ламає ланцюг |
| 32 | 💣 Бомби | вибух 3×3 при очищенні |
| 40 | 🌈 Веселкові блоки | бонус до комбо |
| 55 | 🛡️ Щити | два удари |
| 70 | ☁️ Туман | ховає поле, очищай поруч |
| 90 | 🌀 Портали | телепортують блоки |

### Режими
Classic • Adventure (1000+ рівнів, 8 світів) • Daily Challenge (сід за датою) •
Infinity • Time Rush (120 с) • Hardcore (перешкоди щоходу) • Weekly Tournament (сід за тижнем)

### Мета-ігри
- ⭐ Зірки за рівні (1–3), карта світу з 8 тематичними світами
- 🪙 Монети + 💎 кристали, ⚡ енергія (відновлюється 1/20 хв)
- 🛍️ Крамниця: теми, стилі блоків, ефекти частинок, бустери, преміум
- 🔨 Бустери: молоток, бомба, перемішування, магніт, відміна ходу, стоп-час
- 🎖️ 100 досягнень, 📜 щоденні квести, 🎡 колесо фортуни з серією входів
- 🥇 Турнірна таблиця тижня
- 💾 Автозбереження в localStorage, 🌐 українська/англійська

## Запуск

Просто відкрий `index.html` у браузері (працює і з `file://`, і з будь-якого
статичного сервера):

```bash
npx serve .
```

## Структура

```
index.html        — розмітка екранів, порядок підключення модулів
css/style.css     — стиль (glassmorphism, неон, анімації)
js/
  i18n.js         — локалізація (UA/EN)
  storage.js      — збереження прогресу (localStorage)
  audio.js        — звуки та музика (Web Audio, без файлів)
  ads.js          — шар монетизації (заглушки AdMob/IAP)
  shapes.js       — фігури (класичні + авторські)
  levels.js       — процедурний генератор 1000+ рівнів (детермінований)
  particles.js    — частинки, іскри, тряска, спалахи (пул об'єктів)
  board.js        — логіка поля (лінії, лід, ланцюги, щити, бомби, портали, туман)
  game.js         — контролер гри: рендер Canvas, drag&drop, комбо, режими, бустери
  meta.js         — економіка, енергія, магазин, досягнення, квести, колесо
  ui.js           — екрани, HUD, карта світу, модалки
  main.js         — точка входу
```

## Експорт у Google Play

1. **Обгортка**: [Capacitor](https://capacitorjs.com) (`npx cap add android`),
   Cordova або [Bubblewrap/TWA](https://developer.chrome.com/docs/android/trusted-web-activity/).
   Гра портретна, адаптивна, підтримує safe-area (виріз екрана).
2. **Реклама**: всі виклики йдуть через `js/ads.js` — заміни заглушки
   `showRewarded / maybeInterstitial / refreshBanner` на виклики AdMob SDK
   (наприклад, через `@capacitor-community/admob`). Ігровий код чіпати не треба.
3. **Покупки**: `Ads.purchase()` — підключи Google Play Billing і викликай
   той самий колбек успіху.
4. **Вібрація**: використовується `navigator.vibrate` — у Capacitor працює
   з коробки (дозвіл `VIBRATE` у маніфесті).

## Продуктивність

- Один Canvas 2D, пул частинок без алокацій у кадрі, ~60 FPS на бюджетних пристроях
- `devicePixelRatio` обмежений 2 — чіткість без перевитрат GPU
- Жодних зовнішніх ресурсів: шрифти системні, звук синтезується, іконки — emoji
