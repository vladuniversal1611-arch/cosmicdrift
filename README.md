# 🦊 Останнє Насіння — The Last Seed

Затишна пригода про відродження світу. Після падіння Чорного Метеора майже все
живе зникло — залишилося одне магічне насіння, і його знайшла маленька лисичка.
Очищай землю від темряви, саджай ліси, повертай тварин, будуй поселення та
оживи Дерево Життя.

> Також у репозиторії: **Cosmic Drift** — аркадний космічний шутер
> (`cosmic_drift_v5 (2).html`).

---

## 🎮 Як грати

Уся гра — **один файл** [`index.html`](index.html). Відкрий його в будь-якому
браузері (на телефоні чи компʼютері) — і грай. Інтернет не потрібен.

- **Вертикальна орієнтація**, керування одним пальцем.
- **Автозбереження** кожні 10 секунд + при згортанні (localStorage).
- **Офлайн-прогрес**: будівлі працюють і дерева ростуть, поки тебе немає (до 8 год).
- Працює як **PWA**: у Chrome на Android — «Додати на головний екран».

При першому запуску вбудований **інтерактивний туторіал** веде за руку перші
кроки (очисти → збери → посади → перемагай → ціль острова). Його можна
пропустити, і він більше не зʼявляється.

### Основний цикл
1. 🧹 Торкайся темних тайлів поруч із зеленими — світло ☀️ очищає їх.
2. ⚔️ На деяких тайлах чекають істоти темряви — перемагай їх дотиками.
3. 🌱 Саджай дерева (1 🌰 + 2 💧) — вони ростуть і приносять дари.
4. 🔨 Будуй млин, лісництво, ферму, башту світла… — ресурси йдуть самі.
5. 🐰 Що більше життя на острові — то більше тварин повертається.
6. 🏝️ Відроди острів на 100% → нова глава сюжету → наступний острів.
7. 🖤 У фіналі — бій із Серцем Темряви та посадка Останнього Насіння.

### Що всередині
- 7 островів: Засохлий Ліс, Крижана Долина, Отруйне Болото, Піщана Пустеля,
  Вулканічний Світ, Небесні Острови, Темне Серце Планети.
- **Ізометрична 2.5D-графіка**: острів із об'ємних плиток (висота, грані, тіні) —
  затишний летючий світ, як у справжній будівельній грі.
- 6 ресурсів, 8 будівель, мости через прірви-провалля, покращення в Майстерні.
- 5 видів ворогів + бос.
- Колекція з 45 записів (рослини, квіти, тварини, метелики, насіння, артефакти).
- **211 досягнень**, щоденні завдання, Дерево Життя.
- День/ніч, дощ, веселка, метелики, звірята, частинки магії.
- Генеративна фонова **музика** (тихий пентатонічний ембієнт, тон залежить від
  острова й темніє вночі) + окремі перемикачі звуку та музики в налаштуваннях.
- Скіни лисички за кристали — **без pay-to-win** (точка інтеграції rewarded-реклами
  позначена коментарем у коді: шукай `AdMob` в `index.html`).

## 🤖 Збірка APK для Android

Готовий WebView-проєкт лежить у [`android/`](android):

1. Відкрий папку `android/` в **Android Studio** (Giraffe або новіше).
2. Дочекайся синхронізації Gradle (Studio сама завантажить Gradle 8.5).
3. **Run ▶** — і гра встановиться на телефон/емулятор.
4. Реліз: `Build → Generate Signed Bundle / APK`.

Гра в APK — це та сама `index.html`, покладена в
`android/app/src/main/assets/`. Після зміни гри онови копію:

```sh
./sync-android.sh
```

Іконки застосунку — растрові PNG для всіх щільностей (`mipmap-*`) плюс
адаптивна іконка для Android 8+ (`mipmap-anydpi-v26`), а під час завантаження
показується splash-екран із лисичкою (`drawable/splash.xml`). Матеріали для
магазину: `android/ic_launcher-playstore.png` (512×512) та
`android/feature-splash.png`.

- Мінімальний Android: **5.0 (API 21)**, орієнтація зафіксована портретною.
- Прогрес зберігається в localStorage WebView і переживає перезапуски.
- Оптимізовано для слабких телефонів: статична сцена малюється один раз
  у офскрін-канвас, DPR обмежено 2, ліміт частинок.

## 🧩 Архітектура (як додавати контент)

Весь код `index.html` розбито на модулі, а **весь контент — дані** в обʼєкті
`DATA` на початку скрипта. Додавання нового = один запис у таблицю, без зміни логіки:

| Хочеш додати… | Куди писати |
|---|---|
| Новий острів (тема, вороги, рослини, ціни) | `DATA.islands` |
| Нову будівлю (ціна, виробництво, ліміт) | `DATA.buildings` + малюнок у `Render.building` |
| Нову тварину | `DATA.animalStages` / `DATA.specialAnimals` |
| Нового ворога | `DATA.enemies` + малюнок у `Battle.draw` |
| Сюжетну главу | `DATA.story` |
| Щоденне завдання | `DATA.daily` |
| Досягнення | `DATA.achBase` (тіри генеруються автоматично) |
| Скін лисички | `DATA.skins` |

Модулі: `SaveSys` (збереження) · `Isl` (генерація островів) · `Game` (логіка,
ідл, офлайн) · `Battle` (бої) · `FX` (частинки, погода, день/ніч) · `Critters`
(живність) · `Render` (canvas) · `UI` (вікна) · `Quests` · `Ach` · `Story` · `Snd`.
