# 🔮 Mystic Relics

**Оригінальна казуальна головоломка** у жанрі tile-matching: знаходьте трійки однакових магічних плиток, відкривайте нові шари та очищайте поле. Повністю офлайн, без жодних бібліотек — чистий HTML + CSS + Vanilla JavaScript + Canvas + WebAudio API.

> Гра не копіює жодну існуючу гру: власний набір із **72 унікальних плиток**, оригінальні правила, перепони, бустери, прогресія та UI. Символи маджонгу не використовуються.

## 🚀 Запуск

Проєкт статичний — потрібен лише браузер.

```bash
# Варіант 1: просто відкрити файл
open mystic-relics/index.html

# Варіант 2 (рекомендовано): локальний сервер
cd mystic-relics
npx serve .            # або: python3 -m http.server 8080
# → http://localhost:8080
```

Працює на Android, iPhone, планшетах і ПК (мишею або дотиком). Ціль — 60 FPS.

    └── main.js           # Точка входу, ініціалізація

## 🏗️ Архітектура

- **Модулі-синглтони.** Кожен файл — один глобальний об'єкт (`Board`, `Game`, `UI`, …) з чіткою зоною відповідальності. Жодних збірників — підключення простими `<script>` у правильному порядку (див. кінець `index.html`).
- **Canvas — тільки для гри.** Поле, панель збору, частинки та польоти плиток малюються на одному canvas. Меню, магазин та модальні вікна — звичайний DOM (легше анімувати CSS'ом і локалізувати).
- **Гарантія прохідності рівнів.** Генератор працює методом «зворотного розв'язання»: будується форма рівня, після чого симулюється проходження — на кожному кроці трьом *відкритим* позиціям призначається один тип. Отриманий порядок вилучення і є розв'язком, тож тупики неможливі. Бустер «Перемішати» використовує той самий алгоритм на плитках, що залишилися (з урахуванням «хвостів» у панелі), тому після перемішування рівень теж гарантовано прохідний. Перепони розставляються так, щоб не ламати знайдений розв'язок (замки — лише «після» трійки-ключа у розв'язку).
- **Правило відкритої плитки:** немає плитки зверху **і** вільна хоча б одна бічна сторона.
- **Оптимізації:** спрайт-кеш облич плиток (offscreen canvas на тип+розмір), Object Pooling частинок, перерахунок «відкритості» лише при зміні поля, `devicePixelRatio` cap = 2, фонові частинки меню зупиняються під час гри.

## 📦 Експорт в Android App Bundle (.aab) через Capacitor

### 1. Передумови
- Node.js 18+, JDK 17, Android Studio (SDK 34+)

### 2. Ініціалізація Capacitor

```bash
cd mystic-relics
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android

# webDir вказуємо на корінь проєкту (index.html лежить тут)
npx cap init "Mystic Relics" "com.yourstudio.mysticrelics" --web-dir .

npx cap add android
npx cap sync
```

> Якщо хочете чистішу структуру — перенесіть `index.html`, `css/`, `js/` у папку `www/` і вкажіть `--web-dir www`.

### 3. Іконка та сплеш-скрін

```bash
npm install @capacitor/assets --save-dev
# покладіть assets/icon.png (1024×1024) та assets/splash.png (2732×2732)
npx capacitor-assets generate --android
```

### 4. Підпис релізу

```bash
keytool -genkey -v -keystore mystic-relics.keystore \
  -alias mysticrelics -keyalg RSA -keysize 2048 -validity 10000
```

У `android/app/build.gradle` додайте `signingConfigs.release` з даними keystore (або підпишіть через Android Studio: **Build → Generate Signed Bundle**).

### 5. Збірка .aab

```bash
npx cap open android          # відкриє Android Studio
# Build → Generate Signed Bundle / APK → Android App Bundle → release
# АБО з консолі:
cd android && ./gradlew bundleRelease
# → android/app/build/outputs/bundle/release/app-release.aab
```

### 6. Публікація
Завантажте `.aab` у [Google Play Console](https://play.google.com/console) → Створити застосунок → Production → Create release.

### 7. Підключення AdMob (опційно)

```bash
npm install @capacitor-community/admob
npx cap sync
```

Усі точки інтеграції вже підготовлені у `js/ads.js` (`showBanner`, `maybeInterstitial`, `showRewarded`) — замініть тіла методів на виклики плагіна та задайте свої `adId`. Для банера зарезервовано місце: CSS-змінна `--banner-h` у `css/style.css` (поставте `56px`). IAP: `Ads.purchase()` — точка підключення RevenueCat або `@capacitor/purchases`; ідентифікатори товарів — у `CFG.SHOP` (`js/config.js`).

## 🎮 Правила гри

1. Торкайтеся **відкритих** плиток (без плитки зверху + вільна бічна сторона) — вони летять у панель знизу.
2. **3 однакові** плитки в панелі вибухають і дають очки (комбо ×2…×8 за швидкі серії).
3. Панель має **7 слотів** — переповнення означає поразку (можна врятуватися за кристали або рекламу).
4. Зберіть усі плитки до закінчення часу. Зірки (1–3) залежать від залишку часу.

## 🧪 Тестування

- `Generator` перевірено скриптом: усі 600 рівнів генеруються прохідними (кожна трійка розв'язку відкрита у момент вилучення, кількість плиток кратна 3, без перекриттів у шарі).
- Наскрізний Playwright-тест: меню → рівень → автогра до перемоги → усі екрани, без помилок консолі.
