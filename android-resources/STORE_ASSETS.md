# Store assets — Dragon Blast: Merge Isles

Generated by `node android-resources/make_store_art.js` (uses the painted game
sprites, so the art matches the in-game look). Re-run any time to regenerate.

## Name
- **Store title (Google Play):** `Dragon Blast: Merge Isles`
- **App label on the phone (launcher):** `Dragon Blast`  (set in `capacitor.config.json` → `appName`)
- **Package / appId:** `com.dragonblast.game`

To use a different name, run with env vars, e.g.:
```bash
ART_TITLE='Dragon<br>Isles' ART_SUB='Merge & Blast' node android-resources/make_store_art.js
```
…and update `appName` in `capacitor.config.json`, `name`/`short_name` in
`www/manifest.webmanifest`, and `<title>` in `www/index.html`.

## Files & where they go in Google Play Console
| File | Size | Play Console field |
|------|------|--------------------|
| `playstore-icon-512.png` | 512×512 | **App icon** (Store listing → Graphics) |
| `feature-graphic-1024x500.png` | 1024×500 | **Feature graphic** (Store listing → Graphics) |
| `icon-1024.png` | 1024×1024 | Master icon (source for launcher densities) |

In-app / PWA icons are refreshed too:
`www/assets/icon-512.png`, `www/assets/icon-192.png`.

## Launcher icon on the actual device (after `cap add android`)
The 512/1024 icons above are the Play-Store listing art. To set the **installed
app icon**, drop `icon-1024.png` into an adaptive-icon generator (Android Studio
→ Image Asset, or `@capacitor/assets`) to produce `mipmap-*` densities:
```bash
npm i -D @capacitor/assets
# put icon-1024.png at ./assets/icon.png and a 2732x2732 splash at ./assets/splash.png
npx @capacitor/assets generate --android
```
The icon is designed full-bleed with the dragon inside the center safe zone, so
it survives the circular / squircle adaptive-icon mask (corner gems are bleed).

## Still needed for a full Play listing (not art)
- Screenshots: min 2, phone 16:9 or 9:16 (grab from the running game).
- Short description (≤80 chars) + full description.
- Content rating questionnaire, privacy policy URL, data-safety form.
